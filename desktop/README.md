# Freutigo Aero desktop components

| Directory | Phase | Content |
|---|---|---|
| `themes/` | F2 | Plasma global theme, Aero colour scheme, glass Plasma style, KWin window decoration (Aurorae/QML), SDDM login theme |
| `taskbar/`, `launcher/` | F2 | Plasma panel layout + Windows 7–style launcher (QML, Plasma 6 applet API) |
| `settings/` | F2/F6 | "Freutigo Settings" front end (Qt/QML) over KDE System Settings modules, incl. Aero/Lite mode and GPU profile |
| `shell/` | F5+ | Custom shell work only if measurements justify it (section 7.2) |
| `icons/`, `wallpapers/`, `sounds/` | F2/F6 | **Original** assets only |

Asset rule: nothing Microsoft-owned (themes, icons, wallpapers, sounds, fonts
such as Segoe UI, binaries). Every asset carries its author and licence.
